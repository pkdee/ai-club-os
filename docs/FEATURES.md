# Features

## v0.1 MVP

### Google Login

사용자가 Google 계정으로 안전하게 접속합니다.

### Club

활동 공간을 만들고 기본 정보를 관리합니다.

### Member

Club 구성원과 역할을 관리합니다.

### Session

학습, 실험, 공유가 이루어지는 회차를 관리합니다.

### Attendance

Session별 참여 상태를 기록합니다.

### AI Log

구성원이 사용한 도구, 시도한 내용, 결과, 배운 점, 다음 행동을 Session의 맥락과 함께 기록합니다.

## v0.2 AI Insight

여러 AI Log에서 반복되는 주제, 배운 점, 다음 행동을 찾고 사용자가 검토할 수 있는 형태로 제안합니다.

2026-10-10 에 첫 단계를 만들었습니다. 운영자가 한 회차나 한 달의 AI Log 를 AI 로 정리해 초안을 만들고, 읽어 보고 고치거나 항목을 뺀 뒤 공개합니다. 공개한 것만 Member 에게 보입니다. 항목마다 근거가 된 AI Log 로 갈 수 있습니다.

같은 날 네 가지를 다듬었습니다. 가장 최근에 공개된 AI Insight 의 요약이 Club 개요에 보이고, 지난 회차에 정리된 다음 행동이 그다음 Session 의 개요에 이어집니다. 내용을 글로 복사할 수 있고, 운영자는 고칠 때 항목을 더할 수 있습니다.

## v0.3 Project

AI Log와 Session의 결과를 하나의 프로젝트로 묶고 진행 과정을 관리합니다.

2026-10-11 에 첫 단계를 만들었습니다. Member 는 누구나 Project 를 만들고, 참여자가 이름과 목표, 진행 상태, 할 일, 결과물 링크, 참여자를 고칩니다. 참여자는 자기 AI Log 를 쓰거나 고칠 때 Project 를 골라 묶고, Project 화면에서 묶인 기록을 차례로 봅니다. 운영자는 모든 Project 를 고치고 지웁니다.

같은 날 네 가지를 다듬었습니다. 참여자가 아닌 구성원이 참여를 요청하고 참여자나 운영자가 받아 줍니다. 할 일에 담당자와 기한을 둡니다. Club 개요에 내가 참여하는 Project 가 보입니다. Session 과 Project 가 AI Log 를 거쳐 서로를 보여 줍니다.

들어온 참여 요청과 내가 맡은 할 일은 앱 안의 알림으로도 보입니다.

## v0.4 Web Presentation

프로젝트와 활동 기록을 공개 가능한 웹 발표 형태로 구성합니다.

2026-10-11 에 첫 단계를 만들었습니다. Project 하나의 발표와 Club 의 활동 전체를 보여 주는 발표를 공개하면 링크가 만들어지고, 링크를 아는 사람은 로그인 없이 봅니다. AI Log 는 작성자가 발표에 넣어도 된다고 한 것만 들어가고, 이름은 발표마다 보일지 고릅니다. 공개를 거두면 링크는 바로 쓸 수 없습니다.

같은 날 두 가지를 다듬었습니다. 공개하는 사람이 발표에만 보이는 소개 글을 적습니다. 같은 발표를 한 장씩 넘겨 보는 발표 모드가 있고, 화살표 키와 전체 화면을 씁니다.

## 운영

버전과 따로, Club 을 운영하면서 필요한 규칙입니다. 2026-10-11 에 네 가지를 만들었습니다. 내보낼 때 다시 들어오지 못하게 막을 수 있고, 누가 무엇을 지웠는지 운영자가 봅니다. 작성자는 기록마다 AI Insight 에 쓰지 않게 할 수 있고, AI Insight 는 한 Club 이 하루에 10번까지 만듭니다.

## 알림과 다듬기

2026-10-11 에 미뤄 둔 것을 정리했습니다.

- 알림. Club 안쪽 메뉴에 알림이 있고, 내가 챙길 것(들어온 참여 요청, 기한이 닥쳤거나 지난 할 일)과 새 소식(새로 맡은 일, 참여자가 된 Project, 공개된 AI Insight)을 모아 보여 줍니다. 앱 밖으로는 보내지 않습니다.
- 이름 고치기. Member 는 Club 안에서 보이는 자기 이름을 스스로 고칩니다.
- AI Log 수정 기록. 고칠 때마다 고치기 전의 내용이 남고, 작성자와 운영자가 무엇이 어떻게 바뀌었는지 봅니다.
- 도구 표기 합치기. 운영자가 Club 설정에서 같은 도구의 다른 표기를 하나로 합칩니다.
- Session 시간표. Session 을 만들거나 고칠 때 시간표를 적으면 개요에 보입니다.
- Member 목록 더 보기. Member 를 20명씩 나눠 보여 줍니다.

## 회고

마친 것을 사람이 직접 돌아보는 자리입니다. 2026-10-11 에 만들었습니다.

- Project 회고. 참여자가 Project 화면에서 하나씩 씁니다.
- Session 회고. Member 가 Session 의 회고 탭에서 그 회차가 어땠는지 하나씩 씁니다.
- 한 달 회고. 그 달에 내가 남긴 AI Log, 출석, 적어 둔 다음 행동을 보면서 씁니다.

세 가지 모두 좋았던 것, 아쉬운 것, 다음에 해 볼 것의 세 칸이고 같은 Club 의 Member 가 봅니다. 메뉴의 회고에서 최근에 올라온 것을 모아 봅니다.

2026-10-12 에 회고의 쓰임을 더했습니다. 작성자가 켜면 Session 회고와 한 달 회고는 AI Insight 의 자료로, Project 회고는 그 Project 의 발표에 쓰입니다. 기본은 꺼져 있습니다.

## 남은 운영 규칙

2026-10-11 에 네 가지를 정했습니다. 지운 기록은 1년, AI Log 수정 기록은 90일 동안만 둡니다. 마지막 운영자의 계정이 지워지면 먼저 참여한 구성원이 운영자를 이어받고, 알림으로 알게 됩니다. 참여자가 없는 Project 는 운영자가 맡고, 들어온 참여 요청이 운영자에게 알림으로 갑니다. 스스로 나간 사람은 막지 않습니다.

## 댓글, 표시, 이미지

2026-10-12 에 만들었습니다. AI Log 가 남기는 것으로 끝나지 않고 서로에게 닿게 하려는 것입니다.

- 댓글. 같은 Club 의 Member 가 AI Log 에 댓글을 답니다. 쓴 사람이 고치고, 쓴 사람과 운영자가 지웁니다.
- 도움이 됐어요 표시. 다른 사람의 AI Log 에 한 번 누릅니다. 누가 표시했는지 이름으로 보입니다.
- 알림. 내 기록에 댓글이나 표시가 달리면 알림에 보입니다.
- 이미지. 작성자가 AI Log 에 이미지를 4장까지 붙입니다. 같은 Club 의 Member 만 보고, AI Insight 와 발표에는 쓰이지 않습니다.
- Session 과 Project 잇기. 운영자와 참여자가 회차와 Project 를 직접 잇습니다. 기록이 없어도 어느 회차에서 무엇을 다루는지 보입니다.

## 계정과 개인 정보

2026-10-12 에 만들었습니다.

- 내 계정. 상단의 내 이름을 누르면 내 정보, 화면 모드, 계정 지우기가 있는 화면으로 갑니다.
- 계정 지우기. 스스로 지우고, 그때 내가 쓴 AI Log, 회고, 댓글을 함께 지울지 고릅니다. 붙인 이미지는 언제나 지워집니다. 나만 있는 Club 은 함께 지워집니다.
- 개인 정보 안내. 무엇을 모으고, 어디에 두고, 누가 보고, 얼마나 두는지를 로그인 없이 읽습니다.
- 화면 모드. 기기 설정을 따르거나 밝게, 어둡게를 고릅니다.
