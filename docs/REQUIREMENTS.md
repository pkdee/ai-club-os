# Requirements

## 기능 요구 사항

- 사용자는 Google 계정으로 로그인하고 로그아웃할 수 있어야 한다.
- 사용자는 자신이 속한 Club만 확인할 수 있어야 한다.
- 권한이 있는 사용자는 Club 정보를 관리할 수 있어야 한다.
- 권한이 있는 사용자는 Member와 역할을 관리할 수 있어야 한다.
- 권한이 있는 사용자는 Session을 만들고 수정할 수 있어야 한다.
- 권한이 있는 사용자는 Session별 Attendance를 기록할 수 있어야 한다.
- 구성원은 자신에게 허용된 Club과 Session 안에서 AI Log를 작성할 수 있어야 한다.
- 사용자는 자신에게 허용된 AI Log를 다시 보고 수정할 수 있어야 한다.
- 구성원은 Project 를 만들고, 참여하는 Project 에 자신의 AI Log 와 할 일, 결과물 링크를 묶을 수 있어야 한다.

## 보안과 개인 정보 요구 사항

- 모든 Club 데이터는 소속과 역할을 기준으로 격리해야 한다.
- 데이터 접근 규칙은 화면뿐 아니라 데이터베이스에서도 적용해야 한다.
- 비밀 값은 저장소에 기록하지 않아야 한다. 브라우저로 가는 코드와 남기는 기록에도 드러나지 않아야 한다.
- AI Provider를 도입할 때 전송 데이터와 보관 정책을 사용자에게 알릴 수 있어야 한다. 2026-10-10 기준으로 만들기 전의 확인 창과 AI Log 를 쓰는 화면에서 무엇을 보내는지 알린다.

## 품질 요구 사항

- 기록 기능은 AI Provider 장애와 관계없이 사용할 수 있어야 한다.
- 주요 입력은 작은 화면과 키보드 환경에서도 사용할 수 있어야 한다.
- 오류 메시지는 사용자가 다음 행동을 판단할 수 있게 설명해야 한다.
- 핵심 권한 규칙과 사용자 흐름은 자동 검증할 수 있어야 한다. 2026-10-10 기준으로 권한 규칙과 입력 규칙은 `npm test` 로 검증한다. 화면에서의 사용자 흐름은 아직 자동으로 검증하지 않는다.

## 결정이 필요한 항목

- 내보낸 사람이 다시 들어오지 못하게 막을지 여부. 지금은 초대 링크가 있으면 다시 들어올 수 있다.
- 수정 기록을 남길지 여부
- 누가 무엇을 지웠는지 남길지 여부. 지금은 남기지 않는다.
- AI 로 보내는 것을 사람마다 동의받거나 기록마다 뺄 수 있게 할지 여부. 지금은 보낸다는 사실만 알린다.
- AI Insight 를 만드는 횟수나 비용에 한도를 둘지 여부. 지금은 운영자만 만들 수 있다는 것과 20초 간격만 있다.
- 참여자가 아닌 구성원이 Project 에 스스로 참여하거나 참여를 요청할 수 있게 할지 여부. 지금은 참여자나 운영자가 넣어 줘야 한다.
- Project 의 할 일에 담당자와 기한을 둘지 여부. 지금은 글과 끝냈는지만 있다.
- Session 과 Project 를 직접 이을지 여부. 지금은 AI Log 를 거쳐서만 이어진다.
