# 0029. AI Insight 에 Google 의 Gemini 3.8 Flash 무료 등급을 붙인다

## 상태

채택. 2026-10-20 에 사용자가 정했습니다. `0018-ai-provider-boundary-and-claude.md` 의 경계에 두 번째 구현을 더합니다. Claude 구현은 그대로 둡니다.

## 배경

Vercel 에 배포하면서 AI Insight 를 비용 없이 쓰고 싶다고 했습니다. Claude 는 쓴 만큼 돈이 나갑니다.

2026-10-20 기준으로 Gemini API 의 무료 등급에는 `gemini-3.8-flash` 가 있습니다. 하루에 부를 수 있는 횟수는 Google 이 문서에서 내렸고, 실제로 받은 오류로 확인한 값은 프로젝트마다 하루 20번 안팎입니다.

무료 등급의 약관에는 두 가지가 적혀 있습니다. Google 은 받은 글과 답을 서비스를 개선하는 데 쓰고, 검토하는 사람이 읽을 수 있습니다. 그리고 개인 정보는 무료 등급에 보내지 말라고 합니다. 유럽 경제 지역, 영국, 스위스의 사용자에게는 무료 등급을 쓰지 못합니다.

사용자는 이 조건을 듣고 무료 등급으로 붙이기로 했습니다.

## 결정

### 부르는 방법

- `src/features/ai-insight/provider/gemini.ts` 에 구현을 둡니다. 새 패키지 없이 `fetch` 로 부릅니다.
- Google 이 새 프로젝트에 권하는 Interactions API(`/v1beta/interactions`)를 씁니다. 예전 `generateContent` 는 Google 이 legacy 로 부릅니다.
- 답의 모양은 `response_format` 의 JSON schema 로 정해 줍니다. Claude 에 주던 모양을 그대로 씁니다.
- 생각하는 정도(`thinking_level`)는 `low` 로 둡니다. 기록을 모아 정리하는 일이라 깊이 생각할 필요가 적고, 빠르고 토큰도 덜 씁니다.
- 생각에 쓴 토큰도 출력 한도에 들어가므로 출력 한도를 8192 로 둡니다.
- `store` 를 끕니다. 나중에 이어서 묻지 않으므로 Google 쪽에 대화를 남겨 둘 까닭이 없습니다. 이것으로 무료 등급의 개선 목적 사용까지 막히지는 않습니다.
- 실패해도 다시 보내지 않습니다. 하루 횟수가 적고, 실패한 요청도 횟수를 깎는다는 보고가 있습니다. Claude 구현은 답의 모양을 받지 않으면 한 번 더 보내지만 Gemini 에서는 하지 않습니다.

### 고르는 방법

- `AI_INSIGHT_PROVIDER` 에 `gemini` 를 더했습니다. 비워 두면 키를 넣은 쪽을 쓰고, 두 키가 모두 있으면 예전처럼 Anthropic 을 씁니다.
- 키는 `GEMINI_API_KEY` 로 받습니다. 서버에서만 읽고, 남기는 글에서는 Google 의 키 모양(`AIza...`)도 가립니다.
- 모델은 `AI_INSIGHT_MODEL` 로 바꿀 수 있고, 비우면 `gemini-3.8-flash` 입니다.

### 하루 한도

- Google 이 하루 한도를 넘었다고 답하면 "오늘 쓸 수 있는 횟수를 다 썼다" 고 따로 알립니다. 실패한 까닭에 `quota` 를 더했습니다.
- 한도는 미국 서부 시간 자정에 다시 채워집니다. 한국 시간으로 오후 4시쯤, 11월부터 3월 사이에는 오후 5시쯤입니다.
- 앱이 Club 마다 하루 10번으로 막는 규칙은 그대로입니다. Google 의 한도는 모든 Club 이 함께 씁니다.

### 사용자에게 알리기

- Provider 마다 받은 글을 어떻게 쓰는지 알릴 글(`dataNotice`)을 둡니다. Gemini 구현은 무료 등급의 조건을 적고, Claude 구현은 없습니다.
- 이 글을 네 곳에 보여 줍니다. 개인 정보 안내, AI Insight 를 만드는 확인 창, AI Log 를 쓰는 화면의 기록 안내, Session 회고와 한 달 회고의 "AI Insight 에 써도 됨" 설명입니다.
- 개인 정보 안내는 설정한 Provider 의 이름과 이 글을 읽어 적습니다. 빌드할 때 만들어지는 화면이라 Provider 를 바꾸면 다시 빌드해야 합니다.

## 결과

- AI Insight 를 비용 없이 만듭니다. 대신 동아리 기록의 글이 Google 의 서비스 개선에 쓰일 수 있습니다. 이름, 이메일, 이미지는 예전처럼 보내지 않습니다.
- 하루 20번 안팎이라 Club 두 곳이 한도까지 쓰면 그날은 더 만들지 못합니다.
- 결제를 켜 유료 등급으로 넘어가면 받은 글을 개선에 쓰지 않습니다. 그때는 `gemini.ts` 의 `GEMINI_FREE_TIER_NOTICE` 와 이 기록을 고칩니다. 지금은 키만 보고 무료인지 유료인지 알 수 없어서 언제나 무료 등급의 글을 보여 줍니다.
- 요청과 응답의 모양은 Google 의 문서와 가짜 응답으로 시험했습니다. 실제 키로 부른 결과는 키를 받은 뒤에 확인합니다.
- 유럽 경제 지역, 영국, 스위스의 사용자가 생기면 무료 등급을 쓸 수 없습니다.

## 검토할 대안

- **Claude 를 그대로 씀**: 받은 글을 개선에 쓰지 않습니다. 쓴 만큼 돈이 나갑니다.
- **Gemini 유료 등급**: 받은 글을 개선에 쓰지 않고 한도도 넉넉합니다. 결제를 켜야 합니다.
- **`gemini-3.5-flash-lite`**: 하루 500번 안팎으로 넉넉합니다. 정리의 품질이 조금 낮을 수 있습니다. `AI_INSIGHT_MODEL` 만 바꾸면 쓸 수 있습니다.
- **`generateContent` 로 부름**: 오래 써 온 모양이라 자료가 많습니다. Google 이 legacy 로 부르고 새 프로젝트에는 Interactions API 를 권합니다.
- **Google 의 SDK 패키지를 씀**: 요청 모양을 직접 맞출 필요가 없습니다. 패키지가 하나 늘고, Claude 쪽과 방식이 달라집니다.
