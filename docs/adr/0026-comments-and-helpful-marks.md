# 0026. AI Log 에 댓글과 도움이 됐어요 표시를 두고, Session 과 Project 를 직접 잇는다

## 상태

채택. 2026-10-11 에 정하고 2026-10-12 에 구현을 마쳤습니다. Session 과 Project 를 직접 잇는 것은 `0021` 에서 미뤄 둔 것을 정한 것입니다.

## 배경

AI Log 는 남기는 것으로 끝났습니다. 다른 Member 가 읽고도 반응할 길이 없어 기록이 서로에게 닿았는지 알 수 없었습니다.

Session 과 Project 는 AI Log 를 거쳐서만 이어졌습니다. 어떤 회차에서 어떤 Project 를 다루기로 했는지는 그 회차에 그 Project 의 기록이 남은 뒤에야 보였습니다.

사용자가 네 가지를 정했습니다. 댓글과 도움 표시를 둘 다 둔다. AI Log 에만 둔다. Session 과 Project 를 직접 잇는다. 잇는 사람은 운영자와 그 Project 의 참여자다.

## 결정

### 댓글

- `ai_log_comments` 에 한 줄씩 둡니다. 같은 Club 의 Member 는 누구나 달고, 모두가 봅니다.
- 쓴 사람만 고칩니다. 쓴 사람과 운영자가 지웁니다. AI Log 를 지울 수 있는 사람(`0015`)과 같은 기준입니다.
- 1자 이상 1000자 이하입니다. 답글의 답글은 두지 않고 쓴 순서대로 한 줄로 보여 줍니다.
- 쓴 사람이 Club 에서 나가면 댓글은 작성자 없이 남습니다. AI Log 가 남는 방식과 같습니다.
- 지운 댓글은 지운 기록(`0020`)에 남깁니다. 제목 자리에는 그 댓글이 달려 있던 AI Log 의 제목을 적습니다. 기록을 지우면서 함께 지워진 댓글은 남기지 않습니다.

### 도움이 됐어요 표시

- `ai_log_reactions` 에 사람마다, 기록마다 한 줄을 둡니다. 종류는 하나뿐입니다.
- 자기 기록에는 표시하지 못합니다. 데이터베이스가 막습니다.
- 누가 표시했는지 이름으로 보여 줍니다. 숫자만 보여 주면 누구에게 닿았는지 알 수 없습니다.
- 표시한 사람이 Club 에서 나가면 표시도 지워집니다.

### 알림

- 내가 쓴 기록에 달린 댓글과 표시를 알림(`0023`)에 더했습니다. 알림을 따로 쌓지 않는 방식 그대로, 화면을 열 때 댓글과 표시에서 읽어 냅니다.
- 표시는 기록마다 한 줄로 모아 몇 명이 표시했는지 적습니다.

### Session 과 Project 직접 잇기

- `session_projects` 에 회차와 Project 의 짝을 둡니다.
- 운영자와 그 Project 의 참여자가 잇고 끊습니다. Project 를 고칠 수 있는 사람(`0019`)과 같습니다.
- 화면에서는 직접 이은 것과 AI Log 로 이어진 것을 한 목록으로 합쳐 보여 줍니다. 직접 이은 것이 앞에 오고, 끊을 수 있는 것은 직접 이은 것뿐입니다.
- 회차나 Project 를 지우면 짝도 함께 지워집니다.

### 적용 전

- 마이그레이션을 적용하기 전에는 댓글과 표시 영역, 잇는 칸이 나오지 않고 기존 화면은 그대로 동작합니다.

## 결과

- 댓글과 표시는 AI Insight 로 보내지 않고 발표에도 넣지 않습니다.
- 운영자는 남의 댓글을 지울 수 있지만 고칠 수는 없습니다.
- 표시를 누른 사람의 이름이 보이므로 가볍게 누르기 어려울 수 있습니다. 누가 읽었는지를 아는 쪽을 골랐습니다.
- 댓글에 사람을 불러 알리는 기능은 없습니다. 기록의 작성자에게만 알림이 갑니다.
- 접근 규칙 시험 67건이 남의 댓글을 고치지 못하는 것, 자기 기록에 표시하지 못하는 것, 참여자가 아닌 사람이 잇지 못하는 것을 확인합니다.

## 검토할 대안

- **표시만 둠**: 가장 가볍습니다. 무엇이 도움이 됐는지 말로 남길 수 없습니다.
- **Session 과 Project 에도 댓글을 둠**: 어디서나 이야기할 수 있습니다. 이야기가 흩어지고, 기록이 중심이라는 원칙과 멀어집니다.
- **여러 종류의 표시**: 느낌을 더 나눠 전합니다. 무엇을 고를지 고민이 늘고 화면이 복잡해집니다.
- **표시한 사람을 숨기고 수만 보임**: 누르기 쉽습니다. 누구에게 도움이 됐는지 몰라 다음 이야기로 이어지지 않습니다.
- **운영자만 Session 과 Project 를 이음**: 규칙이 단순합니다. 회차마다 운영자가 모든 Project 를 챙겨야 합니다.
