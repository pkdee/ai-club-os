# 0014. 도구 이름 옆에 로고를 보여 주고, 로고는 패키지의 SVG 파일을 쓴다

## 상태

채택. 2026-10-10. `0013-known-tool-catalog.md` 의 도구 목록 위에 얹습니다.

## 배경

도구 이름표에는 글자만 있었고, 이름표 줄 앞에 공구 아이콘 하나가 있었습니다. 도구 칸에서 고르는 목록도 글자뿐이라 비슷한 이름(Claude, Claude Code, Claude API, Cline)을 눈으로 가려내기 어려웠습니다.

사용자가 아이콘도 같이 넣자고 했고, 종류 아이콘만 쓰는 방법과 실제 로고를 패키지로 설치해 쓰는 방법 가운데 실제 로고를 골랐습니다. 도구 목록에는 119개가 있어 로고를 하나씩 손으로 모으기는 어렵습니다.

## 결정

- 로고는 `@lobehub/icons-static-svg` 1.95.1 의 SVG 파일을 씁니다. MIT 이고 의존성이 없습니다. 버전을 고정합니다.
- 도구와 로고 파일의 짝은 `src/features/ai-log/tool-logos.ts` 에 둡니다. `tool-catalog.ts` 는 로고를 모릅니다. 저장 규칙과 검색이 그림 파일 없이 돌고, 서버 쪽 코드가 그림을 끌어오지 않게 하려는 것입니다.
- 패키지에 색이 있는 파일(`-color`)이 있으면 그것을 그대로 보여 줍니다. 한 가지 색 파일만 있으면 그림을 틀로 삼아 글자색으로 칠합니다. 검은 로고가 어두운 화면에서 사라지지 않게 하려는 것입니다.
- 로고가 없는 도구는 종류 아이콘을 보여 줍니다. 종류는 대화형 도우미, 코딩, 이미지와 영상과 음성, 모델, API, 프레임워크, 데이터, 자동화, 문서의 아홉 가지이고 도구 목록의 `kind` 에 적습니다.
- 목록에 없는 도구는 공구 아이콘을 보여 줍니다.
- 이름표 줄 앞에 있던 공구 아이콘은 뺐습니다. 이름표마다 그림이 들어가므로 같은 뜻을 두 번 말하게 됩니다.
- 그림은 꾸밈입니다. 도구 이름은 항상 글자로 함께 보여 주고, 그림은 화면 낭독기에서 숨깁니다.
- 작은 SVG 라 `next/image` 의 변환을 거치지 않고 `<img>` 로 그대로 보여 줍니다.
- SVG 를 불러오면 받는 값이 주소 글자일 때도 있고 `{ src }` 모양일 때도 있습니다. `logoUrl` 이 둘 다 받습니다.

## 결과

- 119개 가운데 81개에 로고가 붙었습니다. 색이 있는 로고가 55개, 글자색으로 칠하는 로고가 26개입니다. 나머지 38개는 종류 아이콘을 보여 줍니다.
- 패키지에는 파일이 950개쯤 있지만 빌드에는 불러온 73개만 들어갑니다.
- 로고는 각 회사의 상표입니다. 패키지가 MIT 라는 것은 파일을 쓰는 조건이고 상표와는 별개입니다. 지금은 도구를 가리키는 데에만 씁니다. 공개 배포 전에 회사별 상표 지침을 한 번 확인해야 합니다.
- 버전을 고정했으므로 로고 모양은 패키지를 올릴 때만 바뀝니다. 새 도구의 로고가 필요하면 패키지를 올리고 `tool-logos.ts` 에 한 줄을 더합니다.
- 이미 저장된 기록에도 바로 보입니다. 적어 둔 이름이 목록의 도구를 가리키면 한글로 적었든 대소문자가 다르든 같은 로고가 붙습니다.
- 단위 시험이 짝에 적힌 이름이 모두 도구 목록에 있는지, 가장 많이 쓰는 8개 도구에 로고가 있는지, 로고마다 주소가 있는지 확인합니다. 시험에서는 SVG 를 불러오는 자리에 자리 표시 값을 넣습니다(`tests/register.mjs`).
- Figma 의 Badge 에 `Show icon` 과 `Icon` 속성을 더했고, 도구 이름표가 나오는 화면에 모두 반영했습니다. Figma 에는 화면에 나오는 도구와 가장 많이 쓰는 도구의 로고 10개만 컴포넌트로 두었습니다. 전체 목록은 코드가 기준입니다.

## 검토할 대안

- **종류 아이콘만 씀**: 새 패키지가 필요 없고 상표를 신경 쓸 일이 없습니다. 같은 종류의 도구가 모두 같은 그림이 되어 도구를 가려내는 데는 도움이 되지 않습니다.
- **로고 파일을 저장소에 직접 넣음**: 패키지 없이 쓰는 로고만 둘 수 있습니다. 81개를 직접 모으고 출처와 버전을 따로 적어 관리해야 합니다.
- **로고를 바깥 주소에서 불러옴**: 설치할 것이 없습니다. 화면을 열 때마다 다른 서버에 요청이 나가고, 그 서버가 느리거나 멈추면 그림이 비어 보입니다.
- **같은 곳의 React 컴포넌트 패키지를 씀**: 색과 크기를 속성으로 다룰 수 있습니다. 딸려 오는 의존성이 많고, 정적 파일로도 필요한 것이 모두 됩니다.
