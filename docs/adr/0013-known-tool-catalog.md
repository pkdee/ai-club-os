# 0013. 널리 쓰는 AI 도구 목록을 코드에 두고 도구 이름을 그 표기에 맞춘다

## 상태

채택. 2026-10-10. `0012-loose-matching-for-search-and-tools.md` 의 "Club 에서 이미 쓰는 표기에 맞춥니다" 를 넓힙니다.

## 배경

도구 이름을 그 Club 에서 이미 쓴 표기에만 맞추다 보니, 기록이 없는 Club 에서는 맞출 대상이 없었습니다. "chatgpt" 라고 적으면 그대로 저장됐고, 도구 칸에서 고를 목록도 비어 있었습니다. 한글로 "클로드" 라고 적은 것과 "Claude" 도 다른 도구로 쌓였습니다.

사용자가 ChatGPT, Claude, Claude Code, Cursor, Gemini, Antigravity, Codex 같은 도구로 맞추고 찾을 수 있게 하자고 했고, 더 있으면 추가하라고 했습니다.

## 결정

- 널리 쓰는 AI 도구 목록을 `src/features/ai-log/tool-catalog.ts` 에 둡니다. 도구마다 저장하고 보여 주는 표기 하나와, 같은 도구를 가리키는 다른 표기(한글 이름, 줄여 부르는 이름)를 적습니다. 지금 119개가 들어 있습니다.
- 도구 칸은 적는 동안 맞는 도구를 아래에 보여 줍니다. 이 Club 에서 쓰는 도구가 먼저, 그다음 목록의 도구가 나옵니다. 화살표와 Enter, 또는 누르기로 고릅니다. 목록에 없는 도구는 적은 대로 넣습니다.
- 저장할 때 표기를 맞추는 순서는 목록의 표기, Club 에서 쓰는 표기, 입력한 그대로입니다.
- 여러 도구를 함께 가리키는 말은 목록에 넣지 않습니다. "코파일럿" 은 GitHub Copilot 일 수도 Microsoft Copilot 일 수도 있어서 자동으로 맞추지 않고, 고르는 목록에 둘 다 보여 줍니다.
- 찾는 글자에 도구를 가리키는 낱말이 있으면 그 도구의 다른 표기도 함께 찾습니다. "클로드" 로 찾으면 "Claude" 로 적은 기록이 나옵니다. 앱이 낱말을 `클로드|claude` 처럼 넓혀 넘기고, `search_ai_logs` 함수는 `|` 로 이은 것 가운데 하나만 있어도 맞는 것으로 봅니다.
- 도구로 고를 때도 그 도구의 모든 표기를 `|` 로 이어 넘깁니다. 예전에 한글로 적어 둔 기록도 함께 나옵니다.
- 고르는 칸의 도구 목록은 데이터베이스에서 읽은 뒤 목록의 표기로 맞추고, 같은 도구가 된 것은 합칩니다.
- 어느 도구가 어떤 표기를 갖는지는 앱만 압니다. 데이터베이스 함수는 받은 표기를 그대로 씁니다.

## 결과

- 새 도구가 나오면 목록에 한 줄을 더하고 배포해야 합니다. 목록에 없는 도구도 쓸 수는 있지만 표기가 갈릴 수 있습니다.
- 이미 저장된 기록의 도구 표기는 고치지 않습니다. 목록과 고르기, 검색에서는 같은 도구로 묶이지만 기록에는 적은 그대로 보입니다. 그 기록을 다시 저장하면 표기가 맞춰집니다.
- 목록의 표기가 Club 의 표기보다 먼저입니다. Club 이 "chatgpt" 라고 써 왔어도 새로 저장하는 기록은 "ChatGPT" 가 됩니다.
- 찾는 글자에 `|` 를 직접 적으면 그 가운데 하나를 찾으라는 뜻이 됩니다. 일부러 막지 않았습니다.
- 여러 낱말로 된 도구 이름은 찾는 글자 전체가 그 이름일 때만 알아봅니다. "클로드 코드" 는 Claude Code 를 찾지만, "클로드 코드 리뷰" 는 세 낱말을 따로 찾습니다.
- 대소문자와 공백이 아닌 차이는 다른 이름으로 봅니다. "bge-m3" 와 "bge m3" 는 다른 도구입니다.
- 목록의 표기가 서로 겹치지 않는지, 저장할 수 있는 모양인지는 단위 시험이 확인합니다. 검색 함수의 `|` 처리는 접근 규칙 시험 12건으로 확인합니다.

## 검토할 대안

- **도구 목록을 데이터베이스 테이블에 둠**: 배포 없이 도구를 더할 수 있고 검색 함수가 직접 다른 표기를 찾을 수 있습니다. 대신 목록을 관리할 화면과 권한이 필요합니다. 지금은 코드에서 고치는 편이 가볍습니다.
- **Club 마다 도구 목록을 관리**: Club 에 맞는 표기를 쓸 수 있습니다. 운영자가 할 일이 늘고, 널리 쓰는 도구의 표기는 Club 마다 다를 이유가 없습니다.
- **목록에 있는 도구만 고르게 함**: 표기가 갈릴 일이 없습니다. 새 도구를 바로 적을 수 없어 기록이 막힙니다.
- **검색 함수에 표기 묶음을 따로 넘김**: `|` 같은 약속 없이 값의 모양으로 뜻을 전할 수 있습니다. 함수의 값이 늘고 부르는 쪽이 복잡해집니다.
