# 0030. DESIGN.md 를 Google 의 DESIGN.md 형식으로 쓰고 토큰을 시험으로 맞춘다

## 상태

채택. 2026-10-21 에 사용자가 `@google/design.md` 를 설치하고 적용하라고 했습니다. `0001-design-tokens-as-css-variables.md` 의 결정은 그대로 두고, 토큰을 적는 곳을 하나 더합니다.

## 배경

`DESIGN.md` 는 화면과 경험 원칙을 글로만 적은 문서였습니다. 색과 글자 단계의 실제 값은 `src/app/globals.css` 에만 있어서, 화면을 만드는 사람이나 AI 도구가 값을 알려면 CSS 를 읽어야 했습니다.

Google Labs 의 DESIGN.md 형식은 파일 맨 위의 YAML 에 디자인 토큰을 두고, 본문에 그 토큰을 쓰는 이유를 적습니다. `@google/design.md` 는 이 형식을 검사하는 lint 와 토큰을 읽는 함수를 줍니다. 2026-10-21 기준 최신은 0.4.0 이고 형식은 alpha 입니다.

## 결정

- `@google/design.md` 0.4.0 을 개발 도구로 더하고 버전을 고정합니다. `npm run design:lint` 가 형식을 검사합니다.
- `DESIGN.md` 맨 위에 색, 글자 단계, 모서리, 간격, 컴포넌트의 토큰을 둡니다. 색과 글자 단계의 이름은 `globals.css` 의 CSS 변수 이름과 같게 합니다.
- 형식이 정한 여덟 절은 도구가 알아보도록 영문 제목(Overview, Colors 등)을 쓰고 본문은 한국어로 씁니다. 도구는 제목이 정확히 같아야 절을 알아봅니다. 이 제품에만 있는 절(MVP 정보 구조, 화면 설계, 기본 상태)은 그 뒤에 한국어 제목으로 둡니다. 원래 글은 한 줄도 빼지 않고 자리만 옮겼습니다.
- 형식에는 Light 와 Dark 를 나누는 자리가 없습니다. YAML 의 색은 Light 값이고, Dark 값과 Tailwind 클래스 이름은 Colors 절의 표에 적습니다. 그림자도 토큰의 종류에 없어서 표로 적습니다.
- `src/app/design-tokens.test.ts` 가 YAML 의 토큰과 두 표를 `globals.css` 와 견줍니다. 한쪽만 고치면 `npm test` 가 실패합니다.
- 같은 시험이 lint 결과도 봅니다. 아래 두 가지 경고만 받아들이고, 다른 경고는 실패로 봅니다.
  - 어떤 컴포넌트도 참조하지 않는 색. 형식의 컴포넌트에는 테두리 속성이 없어 테두리 색을 적을 수 없고, Figma 에는 있지만 코드에서 아직 쓰지 않는 토큰이 있습니다.
  - 비활성 상태의 대비. WCAG 는 비활성 요소를 대비 기준에서 뺍니다.

## 결과

- AI 도구가 `DESIGN.md` 하나로 색, 글자, 모서리의 정확한 값과 쓰는 방법을 함께 읽습니다.
- `globals.css` 와 `DESIGN.md` 가 어긋나면 시험이 알려 줍니다. 0001 에 적은 대로 Figma 와 코드는 여전히 손으로 맞춥니다.
- 토큰을 고칠 때 `globals.css` 와 `DESIGN.md` 를 함께 고쳐야 합니다. `AGENTS.md` 의 작업 규칙에 적었습니다.
- 대비 검사가 생겼습니다. 컴포넌트 토큰의 면과 글자 색이 WCAG AA 에 못 미치면 시험이 실패합니다. Light 값만 검사하고 Dark 값은 검사하지 않습니다.
- 형식이 alpha 라 패키지를 올리면 규칙이 바뀔 수 있습니다. 올릴 때 `npm run design:lint` 와 `npm test` 를 함께 확인합니다.

## 검토할 대안

- **`DESIGN.md` 에서 CSS 를 만들기**: 패키지의 `export --format css-tailwind` 로 `globals.css` 의 토큰을 만들 수 있습니다. 하지만 이 형식으로는 Dark 모드와 shadcn/ui 의 변수 연결을 나타내지 못합니다. 그래서 `globals.css` 를 기준으로 두고, `DESIGN.md` 는 시험으로 맞춥니다.
- **경고를 없애려고 컴포넌트를 더 만들기**: 쓰지 않는 토큰마다 그것을 참조하는 컴포넌트를 만들면 경고는 사라집니다. 하지만 코드에 없는 컴포넌트를 적게 되어, 그 파일을 읽는 도구가 잘못 배웁니다.
