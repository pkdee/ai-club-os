# 0001. 디자인 토큰을 CSS 변수로 두고 Tailwind 에 연결한다

## 상태

채택. 2026-10-08.

## 배경

화면 설계는 Figma 에서 관리하고, 색은 원시 색과 의미 색 두 층으로 나뉘어 있습니다. 구현은 Tailwind CSS 4 와 shadcn/ui 를 쓰는데, 두 도구 모두 CSS 변수를 테마의 기준으로 삼습니다. 모든 기능이 같은 토큰에 의존하게 되므로 토큰을 어디에 어떤 이름으로 둘지 먼저 정해야 했습니다.

## 결정

- 의미 색은 `src/app/globals.css` 의 `:root` 와 `.dark` 에 CSS 변수로 둡니다. 변수 이름은 Figma 의미 색 변수의 코드 이름과 같게 합니다. shadcn/ui 가 쓰는 이름(`--background`, `--primary`, `--border` 등)은 그대로 쓰고, 없는 것만 더했습니다.
- 값은 Figma 원시 색의 16진수 값을 그대로 적고, 옆에 원시 색 이름을 주석으로 답니다.
- `@theme inline` 으로 의미 색을 Tailwind 색 이름에 연결합니다. 컴포넌트는 `bg-app`, `text-tertiary`, `border-danger-border` 같은 클래스만 씁니다.
- 글자 단계와 그림자는 `@theme` 에 둡니다. 글자 단계는 크기, 줄 높이, 굵기, 자간을 한 이름으로 묶습니다.
- 글자 단계 이름은 `src/lib/utils.ts` 의 `cn` 설정에도 등록합니다.

## 결과

- Figma 에서 색이 바뀌면 `globals.css` 의 값만 고치면 됩니다.
- Dark 모드는 `.dark` 클래스 하나로 전환됩니다. 전환 수단은 아직 만들지 않았습니다.
- 글자 단계 이름을 바꾸거나 더하면 `globals.css` 와 `src/lib/utils.ts` 두 곳을 함께 고쳐야 합니다. 등록을 빠뜨리면 `text-label-m` 같은 클래스가 글자 색으로 분류돼 색 클래스와 합쳐질 때 사라집니다.
- shadcn/ui 가 새로 만드는 컴포넌트는 `cn` 을 패키지에서 바로 가져옵니다. 글자 단계 클래스를 쓰는 컴포넌트는 `@/lib/utils` 의 `cn` 으로 바꿔야 합니다.
- Figma 와 코드의 값은 손으로 맞춥니다. 어긋나도 자동으로 알려 주는 장치는 없습니다.

## 검토할 대안

- **Tailwind 4 기본 팔레트를 참조**: `var(--color-zinc-950)` 처럼 쓰면 값이 짧아지지만, Tailwind 4 팔레트는 Figma 에 넣은 값과 조금 다릅니다. 화면이 Figma 와 미세하게 어긋나는 것을 피하려고 값을 직접 적었습니다.
- **토큰 변환 도구 도입**: Figma 변수를 내보내 CSS 를 생성하는 방식입니다. 토큰이 100개 남짓이고 변경이 잦지 않아 지금은 필요하지 않습니다. 손으로 맞추는 비용이 커지면 다시 검토합니다.
